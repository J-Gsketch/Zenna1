## How to Update This Dashboard

1. **Every Monday:** Pull metrics from Firebase Analytics, Stripe, and support tool
2. **NPS:** Send survey to 20–30 customers on the 1st of each month
3. **Feature Adoption:** Track via event analytics (feature used / total active users)
4. **Churn:** Calculate from Stripe subscription cancellations
5. **Support:** Pull from support ticketing system
