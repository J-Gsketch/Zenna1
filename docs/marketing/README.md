# Zenna Marketing Execution System

> **Hammer & Code** (parent company) · **Zenna** (product #1)
> A structured, systematic operating system where a dedicated marketing agent executes daily/weekly tasks that compound toward the Grand Task: **$300K MRR by Month 12**.

## How to Use This System

1. **Start here:** [MARKETING_GRAND_TASK.md](./MARKETING_GRAND_TASK.md) — the 12-month vision and operating principles.
2. **Hire the operator:** [MARKETING_AGENT_JD.md](./MARKETING_AGENT_JD.md) — role, compensation, success metrics.

   - Quarterly: [QUARTERLY_PHASES.md](./QUARTERLY_PHASES.md)

9. **Plan content:** [CONTENT_CALENDAR_TEMPLATE.md](./CONTENT_CALENDAR_TEMPLATE.md) — Notion/Airtable schema and output targets.

## The Model in One Paragraph

A full-time marketing agent runs a documented daily task list — content, community, partnerships, ads, analytics — while automation (Stripe, SendGrid, Zenna's own AI support) handles the entire customer lifecycle. The founder commits ~1.5 hrs/week (one standup + batched approvals) plus quarterly strategy, and has zero customer-facing involvement. Growth compounds through content, referrals, and an "attach" strategy onto prebuilt complementary software (Xero, MYOB, ServiceM8) and trusted channels (trade associations, government small-business programs). Every task ties to a metric; every metric has a red flag; every red flag forces a decision.
