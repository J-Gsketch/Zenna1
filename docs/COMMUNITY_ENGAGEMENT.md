# Zenna Community Engagement Strategy

Build founder credibility and generate organic trial signups through Reddit,
Facebook groups, and Discord/Slack communities.

---

## Reddit Strategy (r/Plumbing, r/Electricians, trade forums)

1. Spend 1 hour reading top posts to understand pain points.
2. Answer 5–10 questions authentically each week — be helpful, not salesy.
3. When Zenna genuinely fits a question, mention it with context (e.g., "I
   actually built something for this exact problem, happy to share if
   useful").
4. Share a free resource with no promotional pitch, e.g. "Here's a
   spreadsheet template for managing leads."
5. Never post a bare link or ad — Reddit communities downvote and ban
   self-promotion.

**Goal:** Build credibility, generate 2–3 trial signups from organic
mentions.

---

## Facebook Groups (Pick 3 Groups to Be Active In)

Recommended groups: "Plumbers Australia", "Electricians Australia", "Small
Business Tradies".

1. Join and read the group rules before posting.
2. Post daily value content, no promo, e.g. "3 Ways Plumbers Lose Leads
   (And How to Prevent It)".
3. Comment helpfully on others' posts: "Have you tried X?"
4. When someone posts about missing calls or admin overload, mention Zenna
   with context: "I built something for exactly this problem, happy to
   send you a link if you want to try it."

**Goal:** 5–10 trial signups, establish founder credibility.

---

## Discord/Slack Communities

- Look for trade business Slack groups and plumbing/electrical Discord
  servers.
- Apply the same strategy: listen first, answer helpfully, mention Zenna
  only when relevant.

**Goal:** 2–3 trial signups, build founder reputation.

---

## House Rules for All Communities

- Lead with value, not the product — 90% helpful content, 10% mentions.
- Always disclose you're the founder when mentioning Zenna ("full
  disclosure, I built this").
- Respond to every comment/DM within 24 hours.
- Track which community/post generated each signup in
  [METRICS_TRACKING.md](METRICS_TRACKING.md).
