# Customer Onboarding Guide — Zenna by Hammer & Code

Welcome to **Zenna by Hammer & Code**! This guide assists partner businesses and tradies in self-onboarding their business details onto the platform.

---

## 3-Step Self-Onboarding Process

```
┌─────────────────────────┐      ┌─────────────────────────┐      ┌─────────────────────────┐
│  1. Business Profiling   │ ───► │  2. Subscription Plan   │ ───► │ 3. Call Forwarding Sync │
│  Name, Region & Fees    │      │  Starter, Pro, Fleet    │      │  1-Click Carrier Code   │
└─────────────────────────┘      └─────────────────────────┘      └─────────────────────────┘
```

### Step 1: Configure Business Profile
In the Zenna Onboarding Modal:
1. Select your operational country & currency:
   - 🇳🇿 **New Zealand (NZD $)**
   - 🇦🇺 **Australia (AUD $)**
   - 🇺🇸 **United States (USD $)**
2. Input your registered Trading Business Name (e.g. *Auckland Pro Plumbing*).
3. Input the Owner Mobile Number (receives 6 PM executive briefings).
4. Set your standard call-out diagnostic fee (e.g. *$150*).

### Step 2: Choose Subscription Tier
Select from defined plan tiers:
- **Starter (Solo Tradie)**: $99/mo (1 Line, Auto-SMS, 150 Calls, Evening Brief).
- **Pro Team**: $199/mo (3 Lines, Dynamic Prompt, Stripe, Calendar Sync).
- **Enterprise Fleet**: $399/mo (Unlimited Lines, Custom Voice, SLA).

Click **Activate Subscription & Complete Setup** to complete Stripe billing checkout.

### Step 3: Activate Call Forwarding on Mobile
Dial the carrier code on your mobile to route missed calls to Zenna:
- **New Zealand** (One NZ / Spark / 2degrees): `*21*+6421912345#`
- **Australia** (Telstra / Optus / Vodafone): `*61*+61291234567#`
