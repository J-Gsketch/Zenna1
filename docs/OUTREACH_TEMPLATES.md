## Phone/SMS Script (Highest Conversion)

**Opening:**
"G'day [Name], is this a bad time? ... I'll be quick — I built an AI
receptionist for tradies called Zenna. It answers your calls and books jobs
while you're on site, so you stop missing work. Would a free 7-day trial be
useful to test it out?"

**If yes:** "Awesome, I'll send you the setup link by text right now — takes
about 30 minutes and includes a test call so you can hear it in action."

**If hesitant:** "No worries at all — I'll send the link anyway in case you
want to try it later. What's the best number/email?"

**Follow-up SMS (send immediately after call):**
```
Hi [Name], great chatting just now! Here's your free 7-day Zenna trial
link (no card required): [LINK]. Text me if you need a hand setting up.
- [Your Name]
```
