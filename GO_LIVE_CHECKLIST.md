# Zenna go-live checklist

- [ ] Firebase Authentication, Firestore rules and backups enabled
- [ ] GitHub production environment approval configured
- [ ] Stripe live secret, three recurring prices and webhook configured
- [ ] Twilio number routes voice and SMS webhooks to the HTTPS Functions URL
- [ ] Gemini, Twilio and Stripe secrets configured in Functions
- [ ] Sign in, complete onboarding and verify tenant data isolation
- [ ] Place a test call, receive lead SMS, create a deposit and confirm webhook
- [ ] Confirm calendar/Drive integration and customer support contact
- [ ] Publish Terms, Privacy Policy and acceptable-use pages
- [ ] Record first customer's conversion, MRR and support feedback
