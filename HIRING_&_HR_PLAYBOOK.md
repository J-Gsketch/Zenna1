## Recruitment Process

### Stage 1: Define the Role (1 week)
- [ ] Write job description (responsibilities, requirements, nice-to-haves)
- [ ] Define success criteria (what does great look like in 90 days?)
- [ ] Set salary range (benchmark against market)
- [ ] Decide: full-time, part-time, contract, or remote?

### Stage 2: Source Candidates (2–4 weeks)
- [ ] Post on job boards (Seek, LinkedIn, Indeed)
- [ ] Share on social media and network
- [ ] Reach out to passive candidates on LinkedIn
- [ ] Ask team for referrals (offer $500 referral bonus)
- [ ] Consider recruiters for senior roles (15–20% fee)

### Stage 3: Screen (1–2 weeks)
- [ ] Review resumes (10–15 min each)
- [ ] Phone screen top 10 (15 min each)
- [ ] Shortlist top 5 for interviews

### Stage 4: Interview (1–2 weeks)

| Round | Duration | Interviewer | Focus |
|---|---|---|---|
| Phone screen | 15 min | Hiring manager | Culture fit, basic qualifications |
| Technical/skills | 45 min | Team lead | Role-specific skills |
| Culture/values | 30 min | Founder | Values alignment, motivation |
| Final | 30 min | Founder + team | Team fit, questions from candidate |

### Stage 5: Offer (3–5 days)
- [ ] Reference checks (2–3 references)
- [ ] Prepare offer letter
- [ ] Negotiate if needed
- [ ] Send offer with 48-hr deadline
- [ ] On acceptance: start onboarding process

### Interview Questions Bank

#### Culture Fit
- "Why Zenna? What excites you about our mission?"
- "Tell me about a time you had to figure something out with no playbook."
- "What does your ideal work environment look like?"
- "How do you handle feedback?"

#### Technical (Engineering)
- "Walk me through a project you're proud of."
- "How would you design a system that handles 1000 concurrent phone calls?"
- "What's your experience with React/TypeScript/Firebase?"
- "How do you approach testing?"

#### Sales/CS
- "Tell me about a deal you're proud of closing."
- "How do you handle an angry customer?"
- "What's your approach to upselling without being pushy?"
- "How do you prioritise when everything is urgent?"

## Onboarding (New Hire)

### Before Day 1
- [ ] Send welcome email with first-day details
- [ ] Set up accounts (email, Slack, GitHub, Firebase, Stripe)
- [ ] Order equipment if needed (laptop, monitor)
- [ ] Prepare onboarding document/Notion page
- [ ] Assign onboarding buddy

### Day 1
- [ ] Welcome meeting with founder (vision, mission, values)
- [ ] Set up development environment or workspace
- [ ] Introduce to team (Slack announcement + standup intro)
- [ ] Assign first small task (ship something on Day 1!)

### Week 1
- [ ] Complete all account setups
- [ ] Read key documents (this repo's playbooks, SYSTEM_INSTRUCTIONS.md)
- [ ] Shadow a colleague for a day
- [ ] 1-on-1 with direct manager
- [ ] Ship first PR / complete first project

### 30 Days
- [ ] Fully ramped on role responsibilities
- [ ] Completed first project independently
- [ ] 30-day review with manager
- [ ] Set 90-day goals

### 90 Days
- [ ] Fully productive team member
- [ ] 90-day review with founder
- [ ] Performance feedback (what's going well, what to improve)
- [ ] Set quarterly OKRs

## Performance Management

### Quarterly Review Cycle

| Quarter | Focus | Meeting |
|---|---|---|
| Q1 | Goal setting + prior year review | January |
| Q2 | Mid-year check-in | April |
| Q3 | Progress review + adjustment | July |
| Q4 | Annual review + comp review | October |

### Review Format (1-on-1, 45 min)
1. **Wins (10 min):** What went well this quarter?
2. **Challenges (10 min):** What was hard? What did you learn?
3. **Goals (15 min):** Set/review OKRs for next quarter
4. **Feedback (5 min):** Manager gives feedback, employee gives feedback
5. **Career (5 min):** Where do you want to grow?

### Performance Levels

| Level | Description | Action |
|---|---|---|
| Exceptional | Consistently exceeds expectations | Raise, promotion, more responsibility |
| Strong | Meets and sometimes exceeds expectations | Continue, stretch goals |
| Developing | Meets most expectations, some gaps | Coaching, support plan |
| Underperforming | Consistently below expectations | Performance improvement plan (PIP) |

## HR Policies

### Leave Policy

| Type | Allowance | Notes |
|---|---|---|
| Annual leave | 20 days/year (AU standard) | Pro-rated for part-time |
| Sick/personal leave | 10 days/year (AU standard) | No doctor's note for <3 days |
| Public holidays | All AU public holidays | Based on employee's state |
| Parental leave | 12 weeks primary, 2 weeks secondary | Paid, after 12 months tenure |
| Compassionate leave | 2 days per occasion | As per Fair Work Act |

### Remote Work Policy
- **Remote-first:** Work from anywhere in Australia
- **Core hours:** 10am–2pm AEST (for meetings and collaboration)
- **Communication:** Default to async (Slack, Notion). Meetings only when necessary.
- **Equipment:** Company provides laptop, monitor, and peripherals
- **Internet:** $50/month internet stipend
