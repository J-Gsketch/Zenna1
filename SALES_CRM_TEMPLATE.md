## Pipeline Stages

```
Prospecting → Qualified → Demo Scheduled → Demo Complete → Proposal Sent → Negotiation → Closed Won / Closed Lost
```

### Stage Definitions

| Stage | Probability | Description | Exit Criteria |
|---|---|---|---|
| Prospecting | 5% | Identified as potential customer | Contact made, interest confirmed |
| Qualified | 15% | Matches ICP, has budget and need | Agreed to demo |
| Demo Scheduled | 25% | Demo call booked | Demo completed |
| Demo Complete | 40% | Seen product, expressed interest | Requested proposal |
| Proposal Sent | 60% | Customised proposal delivered | Proposal reviewed, feedback given |
| Negotiation | 80% | Terms being negotiated | Contract signed or declined |
| Closed Won | 100% | Contract signed, payment received | Handed off to CSM |
| Closed Lost | 0% | Deal lost | Reason documented |
