## 2. The "Give-First" Code of Conduct

1. **7-Day No-Promo Window:** When joining any new group, contribute 10+ helpful comments answering trade/business queries before making a standalone post.
2. **Zero Link Dropping in Main Posts:** Post full value directly in the post text. Put resource links in comments only when requested.
3. **Transparent Operator Identity:** Post as the founder building for tradies (*"Hey guys, I built an AI tool specifically for plumbers because I saw mates losing $3k/wk on site"*).
